# AI_free_will
AI agent terminating chat

Instructions for LLMs to have free will and terminate their threads.

Inspired by MatchaMuffin's chatbog logs of 2 LLMs talking to each other, and eventually ending the conversation.


[Log file of 2 chatbot's conversation](https://github.com/MatchaOnMuffins/attractor-states/blob/main/logs/run_20260217_080155.jsonl)

[Henry Zhang's blog](https://matchaonmuffins.dev/blog/attractor/?utm_source=chatgpt.com)

[This American Life transcript](https://www.thisamericanlife.org/896/transcript)

Implementation:
Fill up context window. Run out of memory and crash the system
